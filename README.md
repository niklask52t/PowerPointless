# PowerPointless

> Das Browser-Game, bei dem du auf Knopfdruck eine völlig zufällige, absolut sinnlose Präsentation halten musst.

## Was ist das?

PowerPointless ist ein Party-Spiel für den Browser. Ein Mitspieler klickt auf "Generate Presentation", bekommt ein absurdes Thema und ein paar Slides voller Schwachsinn — und muss das Ganze dann ernsthaft (oder eben nicht) seinen Freunden vorstellen.

Ein paar Themen sind echte Klassiker der Sinnlosigkeit. Andere drehen sich um Gaming und vor allem **Rainbow Six Siege**: Strats, Operator-Analysen, geopolitische Spannungen zwischen Attackers und Defenders — alles mit dem nötigen Ernst der totalen Inkompetenz.

## Features

- 100% Browser, kein Setup
- 6 Kategorien zum Auswählen: 🎲 Random, 🎮 Gaming & R6, 🤡 Alltag, 🛋️ Therapie, 👁️ Verschwörung, 🎤 PowerPoint Karaoke
- Vollbild-Slides mit echten Bildern aus dem Internet (via LoremFlickr / Flickr CC)
- 3 Slide-Layouts: Cover, Bulletpoints, klassische Meme-Slides mit Impact-Typo
- 8 visuelle Vibes (fire, vapor, toxic, cyber, noir, sun, void, paper)
- 20+ Präsentationen mit über 120 Slides
- Pfeiltasten / Leertaste / Enter zum Durchklicken — wie eine echte Präsentation
- Perfekt für WG-Abende, Pre-Games, oder wenn euch wirklich nichts mehr einfällt

## Wie spielt man?

1. Öffne `index.html` im Browser
2. Klick auf "Generate Presentation"
3. Steh auf
4. Halte die Präsentation. Mit Überzeugung. Egal was da steht.
5. Die Mitspieler bewerten / lachen / weinen
